Shabbos 69a

שבת ס״ט ע״א

Topic

What counts as שגגה for a חטאת: מונבז vs. רבנן, רבי יוחנן vs. ריש לקיש, the 39 מלאכות, and אביי on שבועת ביטוי

Overview

This amud opens with the רבנן's source that a חטאת is brought only for a sin whose deliberate version carries כרת. The source is a היקש comparing the whole Torah to עבודה זרה. מונבז holds that a person counts as a שוגג even if he only did not know about the קרבן, but the רבנן reject this. Among the רבנן, רבי יוחנן says not knowing about the כרת is enough, while ריש לקיש requires not knowing about both the לאו and the כרת. רבי יוחנן uses ריש לקיש's פסוק for a different law: a משומד does not bring a חטאת. The גמרא then tests ריש לקיש with the משנה of the 39 מלאכות, where a person knew about שבת but not the מלאכות. It answers that he knew about תחומין, which is a Torah law according to רבי עקיבא. A ברייתא that counts someone as a שוגג when he did not know only about the קרבן is shown to follow מונבז. Finally, אביי teaches that for a שבועת ביטוי, a קרבן is brought only if the person did not know the לאו, and the גמרא explains why this needed to be said.
