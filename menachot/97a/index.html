Topic

The שולחן: its status as a wooden vessel, a person's table bringing כפרה, the panels and rods and שבת, and the size of the אמה in the מקדש

Overview

The amud begins with רבי יוחנן's rule that a covered wooden vessel always takes the status of its metal covering. That seems to make the gold-covered שולחן a gold vessel. The גמרא answers that the שולחן is different because a פסוק in יחזקאל calls it 'wood'. That פסוק switches from 'מזבח' to 'שולחן'. רבי יוחנן and רבי אלעזר learn from this that today, without a בית המקדש, a person's table brings כפרה. Next, רב קטינא finds the gold panels and rods of the שולחן in a פסוק in שמות. רבא first challenges this, because handling the rods does not override שבת. He then takes the challenge back, using רבי עקיבא's rule that work which can be done at another time does not override שבת. A ברייתא describes how the rods were taken out before שבת and put back after it, and how many rods each loaf needed. Finally, the גמרא opens a new topic: an argument between רבי מאיר and רבי יהודה about the size of the אמה in the מקדש, which רבי יוחנן says both learn from one פסוק.
