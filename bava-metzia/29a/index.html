Topic

How responsible is a finder for lost money he holds, and can רב יוסף, who says a שומר אבידה is like a שומר שכר, explain the dispute between רבי טרפון and רבי עקיבא?

Overview

The amud opens with the end of a statement limiting the argument between רבי טרפון and רבי עקיבא: they argue only when the finder used the money. If he did not use it and it was lost, everyone agrees he is exempt. The גמרא asks whether this refutes רב יוסף, who holds that a שומר אבידה is like a שומר שכר and pays for theft and loss. רב יוסף answers that everyone agrees the finder pays for theft and loss, and the argument is only about אונסין, which only a שואל pays for. The גמרא challenges him from the word לפיכך in רבי עקיבא's statement. That word teaches something if the argument is about theft and loss, but seems extra on רב יוסף's reading. The answer is that רבי עקיבא said לפיכך only to match רבי טרפון's wording. רבי טרפון's own לפיכך teaches a real point: since the רבנן permitted him to use the money, it is as if he used it. The amud ends with a new challenge to רב יוסף: the משנה says 'if they were lost,' which sounds like loss, not אונסין. The answer comes on the next amud.
