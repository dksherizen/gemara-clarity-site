Topic

Tied bundles and other doubtful materials as סכך, and when stalks count as ידות (handles) of food

Overview

This amud opens by finishing an earlier discussion: the גמרא emends a ברייתא so that something is unfit only if it was as small as its leftover from the start. Next comes the rule against using tied bundles as סכך. מרימר allows the reed bundles of סורא, which are tied only for counting. רבי אבא allows willow huts once the top ties are undone. רב פפא and רב הונא בריה דרב יהושע each defend this, the second by teaching that a tie not meant for carrying is not a real אגד. רבי אבא then quotes שמואל: the vegetables used for מרור count as empty air in a סוכה, because they crumble when they dry. Two versions of רב הונא follow about ידות (handles): grapes picked for wine, or grain cut for סכך. The גמרא asks whether this matches a dispute between תנאים in a ברייתא about branches with fruit on them. רב מנשיא answers that the ברייתא is about grain first cut for food. The גמרא then challenges whether a change of mind can cancel the first intention, and it begins quoting a משנה about vessels that continues on the next amud.
